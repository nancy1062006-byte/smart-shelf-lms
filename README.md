# Smart Shelf LMS

Create a Library Management System (LMS) website name Smart-Shelf for a college project.  

The site should include:

1. **User Roles**

   - Student: can register, log in, search books, issue and return books.

   - Librarian/Admin: can add/remove books, manage users, and view statistics.

2. **Core Features**

   - Login/Register system with authentication.

   - Book catalog with search by title, author, or category.

   - Issue/Return functionality with due date tracking.

   - Admin dashboard showing issued books, overdue books, and inventory.

3. **Tech Stack**

   - Frontend: HTML, CSS, JavaScript (Bootstrap for styling).

   - Backend: Node.js with Express.js OR Python Django.

   - Database: MySQL or PostgreSQL with tables for Users, Books, and IssuedBooks.

4. **Design**

   - Clean, responsive layout suitable for students and librarians.

   - Simple navigation bar (Home, Books, Issue/Return, Admin).

   - Dashboard-style interface for admins.

5. **Deployment**

   - Should run locally for demo purposes.

   - Option to host on Heroku or Vercel.

Make the website functional with CRUD operations, authentication, and a user-friendly interface.
